# Gleam
**A Modern Programming Language**

Features:
* Compiles to machine code for fast execution
* Supports concurrency with lightweight goroutines
* Includes a powerful standard library for efficient development
* Interoperable with other languages through Gleam's foreign function interface

Tech Stack:

* Primary language: Gleam
* Configuration file format: TOML

Getting Started:

1. Install the Gleam compiler and runtime using your platform's package manager or by downloading the binaries from the Gleam website.
2. Create a new Gleam project by running `gleam init` in your terminal.
3. Start coding with Gleam!
